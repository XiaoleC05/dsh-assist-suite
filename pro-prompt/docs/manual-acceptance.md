# 输入增强（pro-prompt）手工验收

自动化覆盖：配置归一化、SiliconFlow 密钥解析、提示词文本、SiliconFlow ASR/chat 请求形状、WAV 校验、语音降级、路由守卫、Host 装配、浏览器半的 WAV 编码/插入/状态机。
仍只能手工验证：真实麦克风与权限弹窗、真实浏览器音频栈、真实 ASR 识别质量、真实 React 渲染与光标位置。

## 前置条件

1. 插件已在 `desktop` 或 `web` profile 安装并启用；重启或刷新页面后，**Plugins** 里显示中文名「输入增强」、包名 `pro-prompt`。
2. SiliconFlow 密钥已写入 profile 级 `apiKey`，可调用 `Qwen/Qwen3-ASR-1.7B` 与 `deepseek-ai/DeepSeek-V4.1-Flash`。
3. 有可用麦克风；页面是 HTTPS 或 localhost（`window.isSecureContext === true`）。
4. 网络可访问 `https://api.siliconflow.cn`。
5. 修改 profile 级 `apiKey` 后，刷新页面；若语音区仍显示未配置，重启一次 DSH。

## 2. 优化按钮：直接执行，无二次确认

1. 在输入框输入一段带口语/歧义的提示词，例如：
   `嗯那个登录页面现在报五百错误你帮我看一下日志然后修一下别动其他功能`
2. 点 ✦（默认结构优化）。
- [ ] 没有弹窗/没有「确认/应用」步骤。
- [ ] 按钮显示 spinner；完成后输入框内容被**直接替换**为优化结果；出现「已用「结构优化」优化并替换输入框」提示。
- [ ] 结果保留 500、登录页面、看日志、别动其他功能等事实；没有编造具体文件、技术栈或验收标准。
3. 结构优化输出检查。
- [ ] 输出包含「角色与目标」「背景与已知事实」「输入」「执行步骤」「可用能力」「约束」「输出格式」「验收标准」等小节（可按任务取舍，但输入/处理/输出/验收必须覆盖）。
- [ ] 「可用能力」只出现当前 profile 真实存在的 skill/插件（如 `dsh-doc`），并说明用途；没有编造 MCP/插件/技能名称。
- [ ] 没有 `【待补充】`、`TODO`、`TBD`、`XXX` 等占位符；关键事实缺失时，末尾是「执行前确认」的最小问题或条件分支。
- [ ] 事实不足时没有编造具体性能指标/文件/框架；执行约定与用户事实分开。
4. 空输入点 ✦：提示「输入框为空，请先输入要优化的内容」，不发请求。
5. 密钥不可用时点 ✦：提示未配置 SiliconFlow 密钥，不发请求；语音识别密钥不可用时点麦克风：提示未配置 SiliconFlow 密钥，不开始录音。
6. 优化期间在输入框继续打字：结果不应覆盖新输入；应插入光标处并提示「优化期间输入有改动，结果已插入光标处」。
7. 连续点击/请求中：按钮禁用，不重复发请求。

## 3. 语音按钮：点击开始，再点停止并输出文本

1. 点麦克风。
- [ ] 首次出现麦克风权限请求；允许后按钮变为红色停止图标，旁边出现红点和计时 `0:0x`。
- [ ] 再点一次：按钮显示 spinner，旁边出现「识别中… / 取消」；完成后识别/润色文本插入输入框；提示「已插入语音识别文本」。
- [ ] 文本已去掉「嗯/那个/然后」等口头禅，标点正常；保真模式下不改变事实/数字/专名。
- [ ] 没有任何历史列表/音频回放/记录。
- [ ] 识别中可点「取消」，回到空闲态且不插入文本。
2. 录音中超过 60 秒：自动停止并识别。
3. 录音不足 0.5 秒：提示「录音太短，请再说一次」，不发请求。
4. 拒绝麦克风权限：提示中文错误，可再次尝试。
5. 只有语气词：提示「没有识别到实质内容」，不插入空文本。
6. 润色失败或润色无有效内容：插入 ASR 原文，并提示「润色未返回有效内容，已插入识别原文」。
7. 识别/润色中断网：提示网络/超时；恢复后可重试；页面不崩。

## 7. 已知限制

- 麦克风需要 HTTPS 或 localhost；桌面版窗口满足。
- 识别是批处理：停止录音后才出结果，不是流式字幕。
- 只接受 16 kHz 单声道 16-bit PCM WAV；浏览器端已重采样，单请求上限 8 MB。
- 默认最长 60 秒是插件保护上限。
- 真实麦克风/真实界面渲染未纳入 CI；本清单用于人工验收。

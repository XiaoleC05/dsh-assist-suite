# 对话助手套件

一个融合插件主体装好三件对话辅助能力。

## 包含

- **长期记忆（Confluence）**：工作区总线（共享状态、便签、消息）、长期记忆候选与用户画像、输出风格卡，8 个工具与只读面板。
- **输入增强（pro-prompt）**：输入框语音输入与提示词优化，面板里可设默认模式。
- **回答质量门禁（Crisp，默认不加载）**：配置里 `crisp.enabled: true` 后才生效，可选用本机 `crisp` 二进制或 DSH 自己的模型评审。

## 用法

安装后：侧栏出现「高级记忆 / Confluence」与「输入增强」面板；输入框左侧多出语音与优化按钮。Crisp 默认不运行、也没有状态页（避免停用状态下出现死页面）。

## 维护

融合入口是 `index.js`，三个成员各自在自己的目录里。改界面后运行 `node scripts/build-client.mjs`；改代码后重启 DSH 或把 bundle 关再开。

## 已知限制

- 只有一行插件，功能不能单独整行停用；Crisp 有配置开关。
- 界面合并在同一个浏览器模块里，任一界面报错会影响整块界面加载。
- 打开 Crisp 需要额外提供评审凭据或改用 `critic: harness`。
